# goInstaller-RU

Русскоязычный установщик и помощник для Ubuntu 24.04 и 3x-ui.

## Возможности

- Проверка окружения Ubuntu и прав root.
- Установка 3x-ui через официальный установочный скрипт проекта.
- Управление службой x-ui и обновление панели.
- Резервное копирование и восстановление конфигурации `/etc/x-ui` и сертификатов `/root/cert`.
- Включение BBR и базовая настройка UFW с сохранением SSH-доступа.
- Диагностика, генерация UUID и вспомогательная генерация ключей REALITY при наличии Xray.

## Требования

- Ubuntu 24.04.
- Архитектура amd64 или arm64.
- Доступ root или запуск через `sudo`.
- Подключение к интернету.

## Сборка

```bash
go build -o goInstaller .
```

## Запуск

```bash
sudo ./goInstaller
```

Либо используйте `build.sh`.

## Настройка VLESS TCP REALITY

После установки откройте панель 3x-ui, создайте inbound с протоколом VLESS, транспортом TCP и security REALITY. Укажите домен назначения (SNI), server name, fingerprint и параметры ключей в соответствии с конфигурацией сервера. Сам установщик не создаёт inbound автоматически.

## Безопасность

Скрипт запускает официальный установщик 3x-ui и выполняет системные изменения. Перед запуском ознакомьтесь с исходным кодом и README. Сделайте резервную копию конфигурации перед обновлением или восстановлением.
