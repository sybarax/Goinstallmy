# goInstaller-RU

Русскоязычный консольный помощник для установки и базового управления 3x-ui на Ubuntu 24.04 LTS.

## Текущие функции

- Проверка запуска от root, версии Ubuntu и архитектуры (amd64/arm64).
- Загрузка и запуск официального установщика 3x-ui из репозитория MHSanaei.
- Просмотр статуса, запуск, остановка и перезапуск службы x-ui.
- Запуск штатного меню x-ui для обновления.
- Базовая диагностика ОС, памяти, диска, службы и TCP-портов.
- Вызов uuidgen и xray x25519 для подготовки данных VLESS + TCP + REALITY (если соответствующие команды установлены).

## Требования

- Ubuntu 24.04 LTS.
- Архитектура amd64 или arm64.
- root-доступ.
- Интернет.
- Для генерации UUID нужен uuidgen; для REALITY keypair — установленный Xray.

## Сборка и запуск

```bash
sudo apt update
sudo apt install -y golang-go curl
git clone https://github.com/sybarax/Goinstallmy.git
cd Goinstallmy
chmod +x build.sh
./build.sh
sudo ./goInstaller
```

После установки открой панель 3x-ui и создай inbound: VLESS, TCP (RAW), REALITY. Установщик не создаёт inbound автоматически; параметры REALITY и клиентские настройки необходимо согласовать в панели.

## Важное замечание

Программа запускает внешний установочный скрипт 3x-ui с GitHub и выполняет системные команды с правами root. Перед использованием изучи исходный код и официальный скрипт. Не публикуй приватные ключи REALITY и учётные данные панели.

Проект находится в разработке. Резервное копирование, настройка UFW и BBR пока не входят в опубликованную версию.
